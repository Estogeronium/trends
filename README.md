# trends — карта трендов «Бренд и креатив 2026»

Статичная страница без сборки: `index.html` + `data.js` + `favicon.svg`.
Сайт `trends.vonzvyagin.ru`.

## Данные

- `data/trends.json` — 159 трендов, выписанных из 9 отчётов (название, суть, доказательство, источник, страница, теги, горизонт, позиция, паттерн).
- `data/evidence_ru.json` — русские формулировки поля «Данные» (цифры и кейсы сверены по числам с оригиналом).
- `build_data.py` — собирает `data.js` из этих файлов. Здесь же редакторские тексты 16 паттернов (название, тезис, «что делать»), пары напряжений и порядок режимов.

Пересобрать: `python3 build_data.py`.

## Как добавить отчёт или тренд

1. Добавьте записи в `data/trends.json` (поле `cluster` — id паттерна из `META` в `build_data.py`, `id` — следующее число).
2. Если у записи есть цифры — добавьте русский текст в `data/evidence_ru.json` по тому же `id`.
3. Если новый источник — добавьте его в список `SRC` в `build_data.py` (счётчик «из 9 отчётов» в интерфейсе возьмёт длину списка автоматически, но шкала сигнала в разметке рассчитана на 9 делений).
4. Запустите `build_data.py`.
